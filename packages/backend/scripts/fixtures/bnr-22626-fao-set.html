Conferinţa mondială F.A.O. Roma 1996 - set

Data emisiunii: 11.11.1996

Argint

Valoare nominală: 100 LEI;
Metal: Argint 925/1000;
Greutate: 27.5 grame;
Dimensiune: rotundă - diametru 37 mm;
Margine: netedă;
Calitate: proof;
Tiraj maxim: 5000.
Avers: La mijloc stema României flancată de două ramuri, una de laur în stânga şi alta de stejar în dreapta. Inscripţia „ROMANIA" este amplasată deasupra stemei, urmînd circumferinţa monedei. Sub stemă este înscrisă valoarea nominală a monedei „100 LEI", iar sub aceasta este inscripţionat anul emisiunii „1996".
Revers: În partea superioară este prezentat globul pămîntesc înconjurat de spicul de grâu ce simbolizează una dintre emblemele organizaţiei FAO. Sub emblema organizaţiei este amplasată pe trei rînduri inscripţia „WORLD FOOD SUMMIT Rome". În partea inferioară, urmînd circumferinţa monedei, este amplasată perioada de desfăşurare a conferinţei, respectiv „13 - 17 NOVEMBER 1996".
